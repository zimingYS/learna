> **状态：** ✅ 已实现（2026-11-27）。项目端点在 `modules/project`，目标/路线/阶段/里程碑/任务在 `modules/roadmap`、`modules/task`；DTO / 状态机 / 事务边界 / 追溯依据见 `设计记录/学习规划模块契约设计.md`。
