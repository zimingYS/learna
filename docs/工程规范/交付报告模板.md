# 交付报告模板

每项任务完成后必须提供以下内容。

## 1. Task Summary

本次任务的目标和完成情况。

## 2. Modified Files

列出新增、修改和删除的文件，说明每个文件的修改原因。

## 3. Implementation Details

解释核心实现、模块职责和关键业务逻辑。

## 4. Code Quality

说明：

- 是否复用了现有代码。
- 是否存在重复实现。
- 是否新增抽象。
- 是否拆分了过长文件或函数。
- 注释是否延续现有风格，是否存在过度注释。
- 是否存在尚未处理的技术债务。

## 5. Database and API Changes

明确说明数据库 Migration、API Contract 和 DTO 是否发生变化。没有变化时明确说明。

## 6. Test Results

列出实际执行的命令和结果，区分：

- Passed
- Failed
- Skipped
- Not Run

## 7. Known Issues

列出尚未解决的问题和潜在风险。

## 8. Design Deviations

说明是否存在与原设计不同的实现。如无差异，明确说明。

## 9. Next Step

仅建议下一项合理任务，不得擅自开始执行。
