# Learna 工程规范

本目录存放 Learna 项目 Agent 和开发者必须遵守的详细工程规范。

## 文档优先级

```text
项目负责人明确指令 > AGENTS.md > docs/工程规范/* > 现有代码风格
```

冲突时停止并报告，不得自行选择。

## 正式设计文档

- `docs/产品需求/Learna产品需求规格说明书V1.0.md`：产品需求基线（PRD V1.0）。
- `docs/架构设计/Learna系统设计方案V1.0.md`：系统设计方案（架构、领域模型概述、API 契约原则、实施路线）。
- `docs/数据库设计/Learna领域模型与ERD设计文档V1.2.md`：领域模型与 ERD（实体、关系、数据字典、索引、删除策略）。
- `docs/模块设计/README.md`：代码级模块设计总览（分层与依赖、M01~M12 模块清单、跨模块约定）；各模块细节见同目录 `M01`~`M12` 分册。

本目录规范与正式设计文档冲突时，同样停止并报告。

## 文档索引

- `开发工作流.md`：强制开发工作流与 Agent 任务执行流程。
- `代码风格与质量规范.md`：代码风格、命名、注释、复用、文件与函数复杂度、语言规则。
- `架构约束.md`：Monorepo 模块边界、前后端和 AI Service 分层与依赖规则。
- `领域模型不变量.md`：领域模型不变量，修改前必须提交 ADR 或设计变更说明。
- `安全与AI约束.md`：数据权威、AI Proposal、可用性和安全约束。
- `数据库与API规则.md`：数据库 Migration 与 API 契约规则。
- `测试与验证.md`：测试原则、测试质量和验证命令。
- `变更管理.md`：范围控制、依赖管理、重构和 Git 工作流。
- `交付报告模板.md`：任务完成后的交付报告模板。
- `AI任务执行模板.md`：AI 任务输入与交付规范。

## 维护规则

- 本目录中的规范与 `AGENTS.md` 冲突时，以 `AGENTS.md` 为准，并暂停报告。
- 不得为了通过检查而删除、弱化或跳过规范。
- 修改领域规则必须先提交 ADR 或设计变更说明。
